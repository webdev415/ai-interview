Next.js Live Transcription Starter
==================================

[](https://github.com/deepgram-starters/nextjs-live-transcription#nextjs-live-transcription-starter)

[![Image 3: Discord](https://camo.githubusercontent.com/0b8cfd255e51923b149e2a3d59369cdb8b406e13d5322d426b40cfcedd9839ae/68747470733a2f2f646362616467652e76657263656c2e6170702f6170692f7365727665722f785752614344427457343f7374796c653d666c6174)](https://discord.gg/xWRaCDBtW4)

The purpose of this demo is to showcase how you can build a NextJS speech to text app using [Deepgram](https://deepgram.com/).

Live Demo
---------

[](https://github.com/deepgram-starters/nextjs-live-transcription#live-demo)

Demo features
-------------

[](https://github.com/deepgram-starters/nextjs-live-transcription#demo-features)

Capture streaming audio using [Deepgram Streaming Speech to Text](https://developers.deepgram.com/docs/getting-started-with-live-streaming-audio).

What is Deepgram?

Quickstart
----------

[](https://github.com/deepgram-starters/nextjs-live-transcription#quickstart)

### Manual

[](https://github.com/deepgram-starters/nextjs-live-transcription#manual)

Follow these steps to get started with this starter application.

#### Clone the repository

[](https://github.com/deepgram-starters/nextjs-live-transcription#clone-the-repository)

Go to GitHub and [clone the repository](https://github.com/deepgram-starters/nextjs-live-transcription).

#### Install dependencies

[](https://github.com/deepgram-starters/nextjs-live-transcription#install-dependencies)

Install the project dependencies.

undefinedshell
npm install
undefined

#### Edit the config file

[](https://github.com/deepgram-starters/nextjs-live-transcription#edit-the-config-file)

Copy the code from `sample.env.local` and create a new file called `.env.local`.

undefinedshell
DEEPGRAM_API_KEY=YOUR-DG-API-KEY
undefined

For `DEEPGRAM_API_KEY` paste in the key you generated in the [Deepgram console](https://console.deepgram.com/).

#### Run the application

[](https://github.com/deepgram-starters/nextjs-live-transcription#run-the-application)

Once running, you can [access the application in your browser](http://localhost:3000/).

npm run dev
